# LE1 Galaxy Map Editor upstream

This project was integrated from
[`AudemusN7/LE1GalaxyMapEditor`](https://github.com/AudemusN7/LE1GalaxyMapEditor)
at commit `2902ae956da90724a5737fc53a0a1646a1e46fef` (version 1.3.1).

LEX-specific adaptations keep the editor as a separate tool window, replace its
prebuilt LegendaryExplorerCore binaries with the solution project, and scope its
resources so it follows LEX's Light, Dark, and ModernDark themes without changing
the editor's ModernDark layout or palette.
